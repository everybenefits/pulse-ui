# Pulse UI

**Pulse UI** is a React design system with shared tokens, theme runtime, and a shadcn-style registry you can copy into your apps.

| Surface | What you get |
|---------|----------------|
| `@pulse/ui` | Primitives, tables, alerts, overlays |
| `@pulse/ui/theme` | Light/dark + accent `ThemeProvider` |
| `@pulse/ui/tokens.css` | CSS variables and utility classes |
| Registry | `public/r/*.json` for `shadcn add @pulse/...` |

## How to use this Storybook

1. Use **Controls** to edit args and **Actions** to inspect callbacks.
2. Toggle **Theme** / **Accent** from the toolbar.
3. Open a component’s **Docs** tab for the API table.
4. Run accessibility checks from the **Accessibility** panel.
